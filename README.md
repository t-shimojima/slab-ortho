# 床版下面オルソ（iPad 用 Web アプリ）

DJI Avata 360 の 360° 静止画から、床版下面の平面オルソ画像を iPad 内で合成するアプリです。
一度ホーム画面に追加すると、通信のない橋の下でも動きます。画像は外部に送信しません。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（合成処理を含む） |
| `sw.js` | オフライン用の仕組み（Service Worker） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコンの設定 |
| `icon-180.png` / `icon-192.png` / `icon-512.png` | アイコン |

## 1. 公開する（GitHub Pages・無料）

オフライン動作には https で公開したページが必要です。GitHub Pages を使う手順です。PC がなくても、iPad の Safari だけで作業できます。

1. https://github.com でアカウントを作成します（無料）。
2. 右上の「＋」→「New repository」を選びます。
   - Repository name：`slab-ortho`（任意の英数字）
   - 「Public」を選択（無料プランで Pages を使う場合は Public が必要です）
   - 「Create repository」を押します。
3. 作成したリポジトリの画面で「uploading an existing file」（または「Add file」→「Upload files」）を押し、このフォルダの **7 つのファイルすべて**を選んでアップロードします。下の「Commit changes」を押します。
4. リポジトリの「Settings」→ 左メニュー「Pages」を開きます。
   - Source：「Deploy from a branch」
   - Branch：「main」、フォルダ「/ (root)」→「Save」
5. 1〜2 分待つと、同じ画面に公開 URL が表示されます。
   例：`https://（ユーザー名）.github.io/slab-ortho/`

> 公開されるのはアプリの仕組みだけです。合成に使う画像や結果は iPad の中にだけ保存され、GitHub には送られません。

## 2. iPad に入れる（ホーム画面に追加）

1. iPad の **Safari** で公開 URL を開きます（通信できる場所で行います）。
2. 画面左上の表示が「● オフラインで使えます」になるまで数秒待ちます。
3. 共有ボタン（□に↑）→「ホーム画面に追加」→「追加」。
4. ホーム画面の「床版オルソ」アイコンから起動します。以後はこのアイコンから使います。

## 3. オフラインで動くか確認する

1. コントロールセンターで機内モードにします。
2. ホーム画面のアイコンから起動し、「オルソ合成」→「サンプルで試す」で合成できれば準備完了です。

## 4. 現場での使い方

1. 機体の microSD を USB-C カードリーダーで iPad に接続し、「ファイル」アプリで `DJI_…_D.JPG` を iPad 内のフォルダにコピーします。
2. アプリの「オルソ合成」で橋梁名・径間番号・撮影日・起終点を入力し、画像を選んで「合成を実行」。
3. 必要なら「範囲を指定」で床版部分を囲み、「この範囲で合成」。
4. 「JPEG を作成」または「PDF を作成」→「保存・共有…」→「"ファイル"に保存」。

合成した案件は自動で iPad 内に保存され、「保存データ」から開き直せます。

## 変状スケッチ（v1.19 で追加・v1.21／v1.22 で改良）

床版下面のオルソ画像の上に、変状をペンで書き込む機能です。

1. 合成後（または「保存データ」から案件を開いた後）、「変状スケッチ」タブを開きます。
2. 上部で変状の種類（ひびわれ・剥離・鉄筋露出・遊離石灰・漏水・その他・うき・変形・欠損・腐食）を選びます。
3. 操作ボタンを選びます。
   - 鉛筆（描く）：なぞる・囲むと記入します。
   - 消しゴム（消す）：消したい変状をなぞります。
   - 十字矢印（移動）：変状の線をつかんでずらします。
   - 重なった四角（複写）：変状の線をつかんでずらすと、同じ形の変状を複写します。
   - 点線の四角と矢印（選ぶ）：変状をタップすると選択・解除します（水色の線）。線幅をまとめて変えるときに使います。
   - 地球マーク（360°画像）：押したあと画面をタップすると、その場所を撮った 360° 画像が開きます（長押しでも開けます）。
   - 戻る：1 つ前の状態に戻します（最大 50 回）。
   - 自由線／矩形：描き方を切り替えます。矩形は対角の 2 点をドラッグして長方形で記入します（ひびわれは常に自由線）。
   - 目のマーク（変状 表示）：記入した変状の表示・非表示を切り替えます。「透過」のつまみで変状を透かして、下の画像を確認できます（どちらも画面だけで、書き出しには影響しません）。
   - NO 表示：変状の番号（赤丸の数字）の表示・非表示を切り替えます。図面の書き出しにも反映されます。
4. Apple Pencil で操作します。指は画面の移動・拡大縮小に使います（「指・マウスで描く」を ON にすると指でも操作できます）。
5. 360° 画像の上でも書き込め、オルソ側に反映されます。
6. 変状一覧の行をタップすると、種類・ひび幅・メモを編集できます。一覧の NO は図の赤丸の数字と同じです（記入した順に 1 から振り直されます）。
7. 線幅・ハッチング線幅：標準は線 0.35 mm・ハッチング 0.20 mm（用紙上の太さ）です。必要な案件だけ、次の 3 通りで変えられます。
   - 変状個別：一覧の行をタップして、線幅・ハッチング線幅を選びます。
   - 変状一括：「すべての変状に適用」。この案件でこれから描く変状にも使われます。
   - 選択して一括：「選ぶ」または一覧のチェックで選び、「選択した変状に適用」。
8. 出力：JPEG / PDF（凡例付き）/ DXF（背景画像付き ZIP）/ 変状一覧 CSV（Excel で開けます）。

- 傾き補正や再合成をしても、書き込みは画像の位置に合わせて自動で追従します。
- 案件を開くときは保存した合成結果を使うため、再合成を待たずに開けます。
- DXF は AutoCAD 2010 形式です。ZIP を展開し、DXF と背景 JPEG を同じフォルダに置いて開いてください（詳しくは ZIP 内の「配置方法.txt」）。
- 対象は床版下面（平面）のみです。主桁・横桁・ハンチには書き込めません。

## 床版の勾配の自動推定（v1.22 で追加）

縦断勾配・横断勾配を測らなくても、画像から自動で求めて合成します。

1. 「オルソ合成」の「床版の勾配」で選びます（標準：自動推定（縦断＋横断を補正））。
   - 自動推定（縦断＋横断を補正）：重なった画像同士のずれ方から、床版の縦断・横断勾配を求めて合成します。
   - 自動推定（縦断のみ補正）：横断方向は水平とみなします。
   - 手入力：図面などの縦断勾配を入れます（従来どおり）。
2. 離隔 h は「画像1（最初の画像）を撮った位置での離隔」として入れます。
3. 合成結果の下に「床版下面の勾配（自動推定）」が表示されます。次回の手入力や撮影計画（高度の調整量）の目安にできます。保存した案件を開いたときも表示されます。

- はっきりした傾きがない場合や、補正すると位置合わせが不安定になる場合は、勾配 0% として合成します（ログに表示）。
- 横断勾配の「左右の向き」は参考表示です。
- 「サンプルで試す」の横で、勾配付きのサンプル（縦断 3% など）を選んで動作を確認できます。

## 変状の選択の解除（v1.22 で追加）

「選ぶ」で選んだ変状（水色の線）は、次のどれかで解除できます。
- 図の右上の「選択解除（○件）」ボタン（選んでいる間だけ表示）
- 「選ぶ」のまま、変状のない所をタップ
- 線幅の欄の「選択を解除」、または一覧の見出しのチェックを外す
- キーボードの Esc キー

## 案件の書き出し・読み込み（v1.24 で追加）

iPad で作った案件を社内 PC に渡し、PC で再合成やスケッチをしてから iPad に戻せます。

1. iPad：「保存データ」→ 案件の「書き出し…」→ 種類を選んで「作成」。
   PC では「作成」を押すとすぐに保存先を選ぶ画面が開き、作成が終わるとそこへ保存されます（v1.27）。保存先を選べないブラウザーでは「ダウンロード」フォルダーに保存されます。進み具合と結果は案件の欄に表示されます。
   - 完全版：360°画像を原本のまま入れます（PC で再合成する場合はこれ）。
   - 閲覧・スケッチ版：360°画像を長辺 4096px に縮小し、合成結果を同梱します（見てスケッチするだけの場合）。
   - スケッチのみ：変状スケッチだけ（数十 KB）。PC から iPad へ戻すときに使います。
2. 「共有（「ファイル」に保存）」で、社内 PC の共有フォルダ（「ファイル」アプリ →「…」→「サーバへ接続」で `smb://PC名` を登録）か SD カードに保存します。共有できないときは「ダウンロード」で保存してから「ファイル」アプリで移します。
3. PC：同じアプリ（Chrome・Edge）の「保存データ」→「ファイルを読み込む…」で取り込みます。
4. 同じ案件がすでにあるときは「スケッチだけ統合」「上書きする」「別の案件として取り込む」から選びます。スケッチは変状ごとに新しい方を採用し、消した変状は消したまま統合されます。

書き出しファイル（.slabortho）は無圧縮の zip です。拡張子を .zip に変えると Windows で中身（360°画像など）を取り出せます。SD カードは exFAT で初期化してください（FAT32 は 1 ファイル 4GB まで）。

## 橋台・壁面・円柱橋脚での変状スケッチ（壁面 v1.25・円柱 v1.26 で追加）

撮影対象を「橋台・壁面（横向き）」「円柱橋脚」にした案件でも、「変状スケッチ」タブで変状を記入できます。使い方は床版下面と同じです（壁面正対図の上でなぞる・囲む、長押しで元の 360°画像を開いてその上でも記入できます）。

- 変状は「元の 360°画像の名前と、その画像の中での向き」で保存します。合成をやり直したり範囲を変えたりしても、壁面正対図の上の位置は自動で追従します。
- 保存・書き出しの形式は v1.24 と同じです。v1.24 とファイルをやり取りしても変状は消えません（v1.24 では壁面の変状は表示されません）。
- 円柱橋脚でも記入できます（展開図の上、または元の 360°画像の上で記入）。展開図の横は柱の周方向の長さなので、ひびわれの長さ・面積は柱の表面での値になります。展開図の左右の端（継ぎ目）をまたぐ変状は、両側に分けて記入してください。
- 小判型・矩形の橋脚は今後対応します。

## 壁の正面方向の自動推定（v1.25 で改良）

「橋台・壁面」で「壁の正面方向」を指定しないときは、水平な型枠目地・天端・床版の縁の曲がり具合から正面方向を自動で求めます（矩形橋脚の面と同じ考え方）。水平な線は 360°画像では曲線に写り、正面方向で最も大きくふくらむことを利用しています。複数の画像の結果を機体の向きでそろえて足し合わせるので、1枚が周囲の景色に引きずられても影響を受けにくくなっています。決められないときは従来の方法に戻り、ログにその旨を表示します。

## 円柱橋脚の合成の安定化（v1.29 で改良）

平三水橋の円柱橋脚で、2回目の飛行の画像が柱の上の方に積み上がって合成に失敗した件への対策です。

- 飛行（電池交換）ごとの高さの差：GPS の絶対高度から求めた差を見込むと撮影範囲の高さが不自然に広がる（1回の飛行の高さの幅の 1.6 倍＋2 m を超える）ときは使わず、同じ離陸地点とみなして画像どうしの照合でそろえます。
- 水面の境目：暗い水面だけでなく、緑がかった明るい水面も色（緑み）の変化で見つけます。見つかれば水面が水平になるように飛行ごとの高さをそろえます。
- 柱の中心の方向：コースごとに柱の輪郭から測った中心の方向が、全コースの中央値から 6° 以上外れるコースは、岸や背景の縦線との取り違えとみなして使いません。
- 離隔の補正：柱の見かけの幅から求めた離隔は、両隣のコースの離隔（高度計）により近いときだけ使います。

## 書き出し中の 360°画像の表示（v1.33）

PC では、案件の書き出しを実行している間も、オルソ画像・変状スケッチから元の 360°画像を開けます（これまでは書き出しが終わるまで反応しませんでした）。iPad では、メモリー不足を防ぐため書き出しの間は開けず、その理由を表示します。合成など他の処理の実行中も、開けない理由を表示します。

## 円柱の展開図の端をまたぐ変状（v1.34）

円柱橋脚の展開図は柱を一周した長さで、左右の端は同じ位置（つなぎ目）です。360°画像で、展開図の右端（左端）の先に変状を記入したときは、反対側の端に表示します。これまでは展開図の外に置かれ、選択も削除もできませんでした。以前に記入して展開図の外にあった変状も、開き直すと反対側の端に表示されます。

## 注意

- **アプリのアイコンを削除すると、保存した案件も消えます。** 報告書に使う JPEG / PDF は「ファイル」に保存しておいてください。
- Safari 本体とホーム画面のアプリは保存場所が別です。案件はホーム画面のアプリ側に保存されます。
- 1 枚 120MP の画像を扱うため、読み込み中は他のアプリを閉じておくと安定します。

## 更新するとき

1. 新しいファイルを同じリポジトリにアップロードし直します（同じ名前で上書き）。
2. 通信できる場所でアプリを 2 回起動し直すと、新しい版に切り替わります。
