# 床版下面オルソ（iPad 用 Web アプリ）

DJI Avata 360 の 360° 静止画から、床版下面の平面オルソ画像を iPad 内で合成するアプリです。
一度ホーム画面に追加すると、通信のない橋の下でも動きます。画像は外部に送信しません。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（合成処理を含む） |
| `sw.js` | オフライン用の仕組み（Service Worker） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコンの設定 |
| `icon-180.png` / `icon-192.png` / `icon-512.png` | アイコン |

## 1. 公開する（GitHub Pages・無料）

オフライン動作には https で公開したページが必要です。GitHub Pages を使う手順です。PC がなくても、iPad の Safari だけで作業できます。

1. https://github.com でアカウントを作成します（無料）。
2. 右上の「＋」→「New repository」を選びます。
   - Repository name：`slab-ortho`（任意の英数字）
   - 「Public」を選択（無料プランで Pages を使う場合は Public が必要です）
   - 「Create repository」を押します。
3. 作成したリポジトリの画面で「uploading an existing file」（または「Add file」→「Upload files」）を押し、このフォルダの **7 つのファイルすべて**を選んでアップロードします。下の「Commit changes」を押します。
4. リポジトリの「Settings」→ 左メニュー「Pages」を開きます。
   - Source：「Deploy from a branch」
   - Branch：「main」、フォルダ「/ (root)」→「Save」
5. 1〜2 分待つと、同じ画面に公開 URL が表示されます。
   例：`https://（ユーザー名）.github.io/slab-ortho/`

> 公開されるのはアプリの仕組みだけです。合成に使う画像や結果は iPad の中にだけ保存され、GitHub には送られません。

## 2. iPad に入れる（ホーム画面に追加）

1. iPad の **Safari** で公開 URL を開きます（通信できる場所で行います）。
2. 画面左上の表示が「● オフラインで使えます」になるまで数秒待ちます。
3. 共有ボタン（□に↑）→「ホーム画面に追加」→「追加」。
4. ホーム画面の「床版オルソ」アイコンから起動します。以後はこのアイコンから使います。

## 3. オフラインで動くか確認する

1. コントロールセンターで機内モードにします。
2. ホーム画面のアイコンから起動し、「オルソ合成」→「サンプルで試す」で合成できれば準備完了です。

## 4. 現場での使い方

1. 機体の microSD を USB-C カードリーダーで iPad に接続し、「ファイル」アプリで `DJI_…_D.JPG` を iPad 内のフォルダにコピーします。
2. アプリの「オルソ合成」で橋梁名・径間番号・撮影日・起終点を入力し、画像を選んで「合成を実行」。
3. 必要なら「範囲を指定」で床版部分を囲み、「この範囲で合成」。
4. 「JPEG を作成」または「PDF を作成」→「保存・共有…」→「"ファイル"に保存」。

合成した案件は自動で iPad 内に保存され、「保存データ」から開き直せます。

## 変状スケッチ（v1.19 で追加・v1.21 で改良）

床版下面のオルソ画像の上に、変状をペンで書き込む機能です。

1. 合成後（または「保存データ」から案件を開いた後）、「変状スケッチ」タブを開きます。
2. 上部で変状の種類（ひびわれ・剥離・鉄筋露出・遊離石灰・漏水・その他・うき・変形・欠損・腐食）を選びます。
3. 操作ボタンを選びます。
   - 鉛筆（描く）：なぞる・囲むと記入します。
   - 消しゴム（消す）：消したい変状をなぞります。
   - 十字矢印（移動）：変状の線をつかんでずらします。
   - 重なった四角（複写）：変状の線をつかんでずらすと、同じ形の変状を複写します。
   - 点線の四角と矢印（選ぶ）：変状をタップすると選択・解除します（水色の線）。線幅をまとめて変えるときに使います。
   - 地球マーク（360°画像）：押したあと画面をタップすると、その場所を撮った 360° 画像が開きます（長押しでも開けます）。
   - 戻る：1 つ前の状態に戻します（最大 50 回）。
   - 自由線／矩形：描き方を切り替えます。矩形は対角の 2 点をドラッグして長方形で記入します（ひびわれは常に自由線）。
   - 目のマーク（変状 表示）：記入した変状の表示・非表示を切り替えます。「透過」のつまみで変状を透かして、下の画像を確認できます（どちらも画面だけで、書き出しには影響しません）。
   - NO 表示：変状の番号（赤丸の数字）の表示・非表示を切り替えます。図面の書き出しにも反映されます。
4. Apple Pencil で操作します。指は画面の移動・拡大縮小に使います（「指・マウスで描く」を ON にすると指でも操作できます）。
5. 360° 画像の上でも書き込め、オルソ側に反映されます。
6. 変状一覧の行をタップすると、種類・ひび幅・メモを編集できます。一覧の NO は図の赤丸の数字と同じです（記入した順に 1 から振り直されます）。
7. 線幅・ハッチング線幅：標準は線 0.35 mm・ハッチング 0.20 mm（用紙上の太さ）です。必要な案件だけ、次の 3 通りで変えられます。
   - 変状個別：一覧の行をタップして、線幅・ハッチング線幅を選びます。
   - 変状一括：「すべての変状に適用」。この案件でこれから描く変状にも使われます。
   - 選択して一括：「選ぶ」または一覧のチェックで選び、「選択した変状に適用」。
8. 出力：JPEG / PDF（凡例付き）/ DXF（背景画像付き ZIP）/ 変状一覧 CSV（Excel で開けます）。

- 傾き補正や再合成をしても、書き込みは画像の位置に合わせて自動で追従します。
- 案件を開くときは保存した合成結果を使うため、再合成を待たずに開けます。
- DXF は AutoCAD 2010 形式です。ZIP を展開し、DXF と背景 JPEG を同じフォルダに置いて開いてください（詳しくは ZIP 内の「配置方法.txt」）。
- 対象は床版下面（平面）のみです。主桁・横桁・ハンチには書き込めません。

## 注意

- **アプリのアイコンを削除すると、保存した案件も消えます。** 報告書に使う JPEG / PDF は「ファイル」に保存しておいてください。
- Safari 本体とホーム画面のアプリは保存場所が別です。案件はホーム画面のアプリ側に保存されます。
- 1 枚 120MP の画像を扱うため、読み込み中は他のアプリを閉じておくと安定します。

## 更新するとき

1. 新しいファイルを同じリポジトリにアップロードし直します（同じ名前で上書き）。
2. 通信できる場所でアプリを 2 回起動し直すと、新しい版に切り替わります。
