DJI Avata 360 での撮影要領

  
360° モードではレンズが上下を向き、上側レンズの中心がほぼ天頂になります。左右レンズのつなぎ目は水平方向にあるため、天頂 ±55° 程度を使うこのアプリでは、本体内でつないだ JPEG をそのまま使えます。

  

    

      
撮影の手順

      
    
        
  1. 桁下高さをレーザー距離計で測り、飛行高度との差から離隔 h を決める（2〜5 m）。
    2. 
        
  2. 「撮影計画」で h を選び、撮影間隔 B とコース間隔 C を確認。床版にチョークで間隔の目印を付けると飛行が安定します。
    3. 
        
  3. 360° モード・静止画・最高解像度（120MP）で撮影。各地点で1〜2秒ホバリングしてから撮るとブレを防げます。
    4. 
        
  4. 橋軸方向に1コース撮ったら横へ C だけずらして戻る。端部は床版の縁より外側まで撮る。
    5. 
        
  5. 縦断勾配がある床版では、1枚進むごとに高度を「撮影間隔 B × 勾配」だけ上げ下げして離隔を一定に保つ（「撮影計画」に目安を表示）。合成時は「縦断勾配」に図面の値を入れると、残った離隔の差も補正します。
    6. 
        
  6. 床版上の既知寸法（目地間隔、スケール板、チョークの 1 m 目印など）を1か所以上写しておく。合成後の縮尺補正に使います。
    7. 
      

    

    

      
注意点

      
    
        
  • 桁下では GNSS が使えず、ビジョン測位も水面上では不安定になります。ラップ率には余裕を持たせてください。
    • 
        
  • 離陸前は撮影できないため、ポール撮影には使えません。
    • 
        
  • RAW（DNG）は左右レンズが別ファイルでつながれていないため、本体生成の JPEG を使います。
    • 
        
  • 桁下は暗いため ISO が上がりがちです。露出補正と、可能なら照明を併用してください。
    • 
        
  • 地覆・張出し・排水管など床版面から外れた部分は二重像になります。損傷図では平面部を主に使ってください。
    • 
        
  • 360° 画像は水平補正済み・機体の向き基準で保存されます。画像の XMP に記録された機体ヨー角を読み取り、画像間の回転の拘束に使います。
    • 
        
  • 同じ形の照明・点検口・排水桝が等間隔に並ぶと誤対応が起きやすくなります。白飛び部分は自動で除外しますが、床版面そのものの模様（型枠跡・汚れ・チョーク印）が写る露出で撮ってください。
    • 
        
  • 桁や壁の近くを飛ぶと、その側面が平面として投影されて歪みます。桁際はコースを1本増やし、桁から離れた位置で撮った画像が使われるようにしてください。
    • 
      

    

  


  

    
画像の取り込み

    
    
      
  1. 機体の microSD を USB-C カードリーダーで iPad に接続し、「ファイル」アプリで DCIM フォルダの JPEG（DJI_…_D.JPG）を iPad 内の任意のフォルダにコピーします。
    2. 
      
  2. このアプリの「オルソ合成」で「ファイルを選択」→「ブラウズ」からコピーしたフォルダを開き、対象の画像をまとめて選びます。
    3. 
      
  3. DJI Fly アプリや「写真」経由で取り込んだ画像は縮小されることがあります。読み込んだ画像が 15520×7760 より小さいと、ログに注意が表示されます。
    4. 
    

  

  

    
橋台・壁面を撮るとき（橋台モード）

    
    
      
  1. 「オルソ合成」の撮影対象で「橋台・壁面（横向き）」を選び、離隔 D（カメラから壁面まで）を入力します。
    2. 
      
  2. 機首を壁に向けたまま、壁に沿って水平に飛びます。撮影間隔とコース間隔は「撮影計画」の壁面の表を使います。
    3. 
      
  3. 画像を選んだら「壁の正面方向」の「画像で指定…」を押します。天端と床版の境目や打継目など壁の水平な線の左右2か所をタップすると、正面方向を正確に計算します（壁の中央を1点タップするだけでも可）。機体が壁の中央からずれていても正しく正対します。
    4. 
      
  4. 「水平線付近の除外」は標準の ±3° で使います。水平線の近くはやや甘く写りますが、ほかの画像に同じ箇所が写っていればそちらを優先します。画質を優先したいときは ±6°〜±15° に変えると、合成し直さずに反映されます。
    5. 
      
  5. 離隔が取れない短い橋でも、機体の高さを1m程度ずつ変えて2〜3枚撮れば壁の上下を覆えます。合成後は「範囲を指定」で壁の部分に絞り、型枠の目地など実寸の分かる箇所で「縮尺を補正」してください。
    6. 
    

  

  

    
橋脚を撮るとき（円柱橋脚・小判型橋脚）

    
    
      
  1. 「撮影計画」タブの「橋脚の撮影計画」に、柱の寸法・高さ・離隔を入れると、コースの位置・機首の向き・撮影する高さ・枚数が出ます。
    2. 
      
  2. 円柱：左岸側から時計回りに、柱の中心へ機首を向けて一周します。コースの間隔は30°以内。各コースで下から上（または上から下）へ、2m以内の間隔で撮ります。
    3. 
      
  3. 小判型：前面（F1…）は面に直角に機首を向け、平面部の左右に1.5m程度の間隔で並べます。両端（S1・S2）は半円の中心に機首を向けて1コースずつ。背面も前面と同じです。平面部の列は左右対称に配置してください（面の中心の推定に使います）。
    4. 
      
  4. 各コースは高さだけを変えて撮ります（横に流されない、機首を回さない）。高さの違う画像から離隔を自動で補正するため、最低2段は撮ってください。30MPの静止画で十分です。
    5. 
      
  5. 合成は「撮影対象」で「円柱橋脚」または「小判型橋脚」を選び、直径（または幅・厚さ）と計画した離隔を入れて「合成を実行」。小判型は「前面・右端・背面・左端」のボタンで面を切り替え、面ごとに JPEG・PDF を保存します。
    6. 
      
  6. 円柱の展開図には C1 の位置に「左岸側」、反対側に「右岸側」の線が入ります。縮尺は機体の高度計を基準にしているため、±10%程度の誤差があります。図面の寸法があれば「距離を測る」で補正してください。
    7. 
    

  

  

    
合成画像の傾きを直す

    
    
      
  1. 合成時は、型枠の目地や床版の縁などの直線を手がかりに自動で水平に合わせます（「自動水平補正」）。
    2. 
      
  2. まだ傾いているときは「傾きを補正」を選び、床版の縁や目地に沿って2点をタップします。線が水平（または垂直）になる角度が入り、画面で確認できます。
    3. 
      
  3. ±0.1°・±1° のボタンや数値で微調整し、青い補助線と平行になったら「この角度で合成」を押します。範囲指定は解除されるので、必要なら指定し直してください。
    4. 
    

  









  

    
壁の正面方向を指定

      

    
1点：壁の中央をタップ（正面の向きは自動で微調整）　2点：天端・打継目など壁の水平な線の左右2か所をタップ（向きを正確に計算）。線が水平線（赤帯）から離れて写っている画像を選ぶと正確です。iPad は横向きが見やすくなります。
