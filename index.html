DJI Avata 360 での撮影要領

  
360° モードではレンズが上下を向き、上側レンズの中心がほぼ天頂になります。左右レンズのつなぎ目は水平方向にあるため、天頂 ±55° 程度を使うこのアプリでは、本体内でつないだ JPEG をそのまま使えます。

  

    

      
撮影の手順

      
    
        
  1. 桁下高さをレーザー距離計で測り、飛行高度との差から離隔 h を決める（2〜5 m）。
    2. 
        
  2. 「撮影計画」で h を選び、撮影間隔 B とコース間隔 C を確認。床版にチョークで間隔の目印を付けると飛行が安定します。
    3. 
        
  3. 360° モード・静止画・最高解像度（120MP）で撮影。各地点で1〜2秒ホバリングしてから撮るとブレを防げます。
    4. 
        
  4. 橋軸方向に1コース撮ったら横へ C だけずらして戻る。端部は床版の縁より外側まで撮る。
    5. 
        
  5. 床版上の既知寸法（目地間隔、スケール板、チョークの 1 m 目印など）を1か所以上写しておく。合成後の縮尺補正に使います。
    6. 
      

    

    

      
注意点

      
    
        
  • 桁下では GNSS が使えず、ビジョン測位も水面上では不安定になります。ラップ率には余裕を持たせてください。
    • 
        
  • 離陸前は撮影できないため、ポール撮影には使えません。
    • 
        
  • RAW（DNG）は左右レンズが別ファイルでつながれていないため、本体生成の JPEG を使います。
    • 
        
  • 桁下は暗いため ISO が上がりがちです。露出補正と、可能なら照明を併用してください。
    • 
        
  • 地覆・張出し・排水管など床版面から外れた部分は二重像になります。損傷図では平面部を主に使ってください。
    • 
        
  • 360° 画像は水平補正済み・機体の向き基準で保存されます。画像の XMP に記録された機体ヨー角を読み取り、画像間の回転の拘束に使います。
    • 
        
  • 同じ形の照明・点検口・排水桝が等間隔に並ぶと誤対応が起きやすくなります。白飛び部分は自動で除外しますが、床版面そのものの模様（型枠跡・汚れ・チョーク印）が写る露出で撮ってください。
    • 
        
  • 桁や壁の近くを飛ぶと、その側面が平面として投影されて歪みます。桁際はコースを1本増やし、桁から離れた位置で撮った画像が使われるようにしてください。
    • 
      

    

  


  

    
画像の取り込み

    
    
      
  1. 機体の microSD を USB-C カードリーダーで iPad に接続し、「ファイル」アプリで DCIM フォルダの JPEG（DJI_…_D.JPG）を iPad 内の任意のフォルダにコピーします。
    2. 
      
  2. このアプリの「オルソ合成」で「ファイルを選択」→「ブラウズ」からコピーしたフォルダを開き、対象の画像をまとめて選びます。
    3. 
      
  3. DJI Fly アプリや「写真」経由で取り込んだ画像は縮小されることがあります。読み込んだ画像が 15520×7760 より小さいと、ログに注意が表示されます。
    4.
